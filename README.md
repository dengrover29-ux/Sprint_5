# Sprint_5: Автотесты для Stellar Burgers

Проект учебного финального спринта: автоматизированные тесты на Selenium + pytest
для учебного сервиса Stellar Burgers (сборка и заказ бургеров).

## Что проверяется
- Регистрация: успешная регистрация и ошибка при некорректном пароле (меньше 6 символов).
- Вход: по кнопке «Войти в аккаунт», через «Личный кабинет», через форму регистрации
  и через форму восстановления пароля.
- Переход в личный кабинет по клику на «Личный кабинет».
- Переходы из личного кабинета в конструктор: по кнопке «Конструктор» и по логотипу.
- Выход из аккаунта по кнопке «Выйти».
- Переключение разделов конструктора: «Булки», «Соусы», «Начинки».

## Структура проекта
- `tests/` - автотесты, сгруппированы по функциональности.
- `locators.py` - описание локаторов с комментариями.
- `page_objects.py` - объектные модели страниц.
- `conftest.py` - фикстуры и генераторы email и пароля.

## Установка
1. `python -m venv venv`
2. `venv\Scripts\activate`
3. `pip install -r requirements.txt`

## Запуск
`pytest -v`

Тесты рассчитаны на Google Chrome. Для регистрации используется почта
в формате имя_фамилия_когорта_3цифры@yandex.ru - она генерируется автоматически,
так что каждый прогон получает уникальную учётную запись.
